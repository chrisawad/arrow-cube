# Arrow Cube icon artwork

`source-corner.png` is an exact, tighter crop of the user's original gameplay screenshot, `1765.png`. The arrows keep their original game geometry. No generated artwork or retouching is used.

The original screenshot is 575 × 1280 pixels. The crop is 280 × 280 pixels, from left 145, top 495, right 425, bottom 775 (right and bottom exclusive).

Normal builds use the checked-in PNG/ICO exports. Run `python scripts/build-icons.py` to regenerate them. The `arrow-cube-corner-v2-*` filenames let installed PWAs detect the revised artwork. The manifest URL and app identity stay the same.
