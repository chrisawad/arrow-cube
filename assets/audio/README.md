# Win cheer

The optional `you-win.wav` is the boy-style **You win!** take selected by Chris. The “You win!” voice setting is off by default and saved separately from the main Sound setting. When enabled, it plays before the trumpet fanfare. Turning it off keeps the trumpet; the main Sound setting mutes all audio.

This fictional child-style AI voice was generated for Arrow Cube on 2026-11-15 using the free official [Qwen3-TTS demo](https://huggingface.co/spaces/Qwen/Qwen3-TTS), with the [Qwen3-TTS-12Hz-1.7B-VoiceDesign model](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-VoiceDesign). The model is released under Apache-2.0. This is generated speech, not a recording or clone of a real child.

No ElevenLabs or stock recordings are included. The installed game plays this bundled file locally; it does not contact a speech service or need an account.

The take used the text `You win!`, language English, and this voice description:

A cheerful young boy character with a bright, slightly husky childlike voice, cheering loudly for a friend who just won a game. Joyful and energetic, smiling broadly, emphatic rising You and celebratory WIN. Natural clear American English. Say only the short phrase, one clean voice, no music or effects. Fictional generic character, not an imitation of any real person.
