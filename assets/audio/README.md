It was generated for Arrow Cube on 2026-11-15 using the free official [Qwen3-TTS demo](https://huggingface.co/spaces/Qwen/Qwen3-TTS), with the [Qwen3-TTS-12Hz-1.7B-VoiceDesign model](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-VoiceDesign). The model is released under Apache-2.0. This is generated speech, not a recording or clone of a real child.

No ElevenLabs or stock recordings are included. The installed game plays this bundled file locally; it does not contact a speech service or need an account.
